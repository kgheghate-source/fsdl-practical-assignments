# 🌐 Personal Portfolio Website

A modern, fully responsive **Personal Portfolio Website** built using **HTML5, CSS3, Bootstrap, and JavaScript**. The website showcases my education, technical skills, projects, certifications, experience, and contact information in a clean and professional interface. It also integrates **EmailJS** to enable visitors to send messages directly without requiring a backend server.

---

## 📖 Project Overview

This project was developed as part of the **Full Stack Development Laboratory (FSDL)** practical assignments. The main objective was to create a professional portfolio that highlights personal achievements, technical expertise, and completed projects while implementing responsive web design principles.

The website is optimized for desktops, tablets, and mobile devices, ensuring a seamless user experience across different screen sizes.

---

## 🎯 Objectives

- Design a responsive personal portfolio using HTML and CSS.
- Apply modern UI design principles using Bootstrap.
- Organize personal and professional information effectively.
- Implement a fully functional contact form using EmailJS.
- Strengthen front-end development skills through a real-world project.

# 📧 Contact Form

The contact form is integrated using **EmailJS**, allowing users to send messages directly from the website without requiring a backend server.

### Workflow

1. User enters:
   - Name
   - Email
   - Message

2. JavaScript validates the input.

3. EmailJS securely processes the request.

4. The message is delivered to the registered email address.

5. A success notification is displayed after successful submission.
