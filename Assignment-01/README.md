Title:
Design a Static Web Page Displaying All HTML Text Formatting Tags in a Table Format
Objectives:
● To create a static web page that presents various HTML text formatting tags in a
well-structured tabular layout.
● To learn the function and usage of different formatting tags by showing their tag name,
explanation, sample code, and corresponding output.
● To enhance understanding of HTML table elements by organizing information clearly and
systematically.
● To gain hands-on experience in writing HTML code and analyzing how different formatting
tags modify the appearance and meaning of text in a browser.
Software and Hardware Requirements:
● A computer or laptop with basic specifications (at least 4GB RAM recommended).
● Any operating system such as Windows, Linux, or macOS.
● A text editor like Notepad, Visual Studio Code, or Sublime Text for writing HTML code.
● A web browser such as Google Chrome, Mozilla Firefox, or Microsoft Edge to run and test the
web page.
Theory:
HTML (HyperText Markup Language) is the standard language used to design and structure web
pages. It uses different tags and elements to define how content appears in a browser. HTML consists
of opening and closing tags that help display text, images, links, tables, and other web components.
Text formatting tags in HTML are used to change the style or importance of text content. These tags
make web pages more readable and help emphasize important information. Some tags change the
visual appearance of text, such as <b> for bold text, <i> for italic text, and <u> for underlined text.
Other tags add meaning to the content, like <strong> to indicate important text and <em> to
emphasize text semantically.
There are also additional formatting tags including <mark> to highlight text, <small> to reduce text
size, <del> to show deleted text, <ins> to indicate inserted text, <sub> for subscript, <sup> for
superscript, <code> to display programming code in a fixed-width font, and <pre> to show
preformatted text while preserving spaces and line breaks.
In this assignment, all these formatting tags are displayed in a tabular format. Using an HTML table
helps organize the tag name, description, example, and output in a clean and understandable way.
Tags Used in This Assignment:
● <html> – The main root element of an HTML document.
● <head> – Contains metadata and information about the webpage.
● <title> – Specifies the title shown on the browser tab.
● <body> – Holds the visible content of the webpage.
● <b> – Displays text in bold style.
● <strong> – Represents important text (generally bold).
● <i> – Shows text in italic format.
● <em> – Adds emphasis to text (usually italic).
● <u> – Underlines the text.
● <mark> – Highlights text with a background color.
● <small> – Displays text in a smaller font size.
● <del> – Represents deleted text with a strike-through effect.
● <ins> – Indicates inserted text, typically underlined.
● <sub> – Displays subscript text below the normal line.
● <sup> – Displays superscript text above the normal line.
● <code> – Shows programming code in a monospace font.
● <pre> – Preserves formatting such as spaces and line breaks.
● <q> – Defines a short inline quotation.
● <blockquote> – Defines a longer quotation block.
● <abbr> – Represents an abbreviation and shows the full form when hovered over.
