# 📖 Assignment 1 - HTML Text Formatting Tags

## 📌 Overview

This project demonstrates the implementation of various **HTML Text Formatting Tags** using a well-structured table layout. The webpage displays the tag name, its purpose, sample HTML code, and the corresponding browser output, making it an excellent reference for understanding HTML text formatting.

---

## 🎯 Objectives

- Understand the purpose of different HTML text formatting tags.
- Create a clean and organized static webpage using HTML.
- Display HTML tags in a tabular format for better readability.
- Learn the difference between visual formatting and semantic formatting.
- Strengthen the fundamentals of HTML document structure.

---

## ✨ Features

- 📑 Static HTML webpage
- 📋 Table-based layout
- 🔤 Demonstrates all commonly used HTML formatting tags
- 💻 Displays example code and browser output
- 🎨 Simple, clean, and beginner-friendly UI

## 📚 HTML Tags Covered

The project demonstrates the following HTML tags:

- `<b>` — Bold Text
- `<strong>` — Important Text
- `<i>` — Italic Text
- `<em>` — Emphasized Text
- `<u>` — Underlined Text
- `<mark>` — Highlighted Text
- `<small>` — Smaller Text
- `<del>` — Deleted Text
- `<ins>` — Inserted Text
- `<sub>` — Subscript Text
- `<sup>` — Superscript Text
- `<code>` — Programming Code
- `<pre>` — Preformatted Text
- `<q>` — Inline Quotation
- `<blockquote>` — Block Quotation
- `<abbr>` — Abbreviation
