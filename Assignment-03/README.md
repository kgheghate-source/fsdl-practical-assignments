# 🛒 Mini E-Commerce Store

A responsive **Mini E-Commerce Web Application** developed using **HTML5, CSS3, JavaScript, and Bootstrap**. The application simulates the basic workflow of an online shopping platform, allowing users to browse products, add items to a cart, proceed to checkout, and generate a final bill dynamically.

---

# 📖 Project Overview

This project was developed as part of the **Full Stack Development Laboratory (FSDL)** coursework. It focuses on implementing core front-end development concepts, including **DOM manipulation**, **event handling**, **dynamic UI updates**, and **responsive web design**.

The application demonstrates how a basic online shopping website functions by providing an interactive shopping experience without using any backend technologies.

---

# 🎯 Objectives

- Develop a dynamic e-commerce web application.
- Display products using an organized grid layout.
- Implement Add-to-Cart functionality.
- Dynamically update cart items and total amount.
- Simulate a complete checkout workflow.
- Strengthen JavaScript and DOM manipulation concepts.
