# 🌦️ Interactive Weather Monitoring Dashboard

An interactive **Weather Monitoring Dashboard** developed using **HTML5, CSS3, JavaScript, and D3.js**. The dashboard visualizes weather data through dynamic charts and graphs, enabling users to analyze temperature, humidity, and rainfall trends across multiple cities.

---

# 📖 Project Overview

This project was developed as part of the **Full Stack Development Laboratory (FSDL)** coursework. It demonstrates the use of **D3.js (Data-Driven Documents)** to build interactive and animated data visualizations for real-world weather analysis.

The dashboard allows users to select different cities from a dropdown menu and instantly view weather trends through interactive charts, making data analysis simple and visually appealing.

---

# 🎯 Objectives

- Design an interactive weather monitoring dashboard.
- Visualize weather data using Line Charts and Bar Charts.
- Implement dynamic data visualization using D3.js.
- Display real-life weather parameters such as temperature, humidity, and rainfall.
- Understand graphical representation of data for better analysis.
